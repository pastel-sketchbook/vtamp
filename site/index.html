Not another window.

We loved the little player that lived on our desktop. These days, we live in a terminal. The music should feel at home here, too.

Album covers come through in high resolution with Sixel or Kitty graphics, automatically detected when you attach. Ghostty + tmux uses Kitty; Sixel in tmux requires support from both tmux and the outer terminal. Color halfblocks keep the artwork visible when pixel graphics aren’t available.

Make it feel like your terminal. Choose from nine color themes, including cozy Catppuccin Mocha, light Latte, Rosé Pine, and the original green Classic. Press t to preview, then Enter to save for your next attachment. Mocha is the default.

$ vtamp

q

Step out.

The interface closes. The server keeps playing. Get your pane back for the work in front of you.

$ vtamp

Pick up.

Attach again from another pane. Same music. Same queue. Exactly where it is now.

TUIPLAYBACK SERVERCLI / AGENTS

One shared queue. As many interfaces as you need.

Now playing, in your tmux bar.

Close the player and keep the current track in sight. The optional tmux plugin shows the song title and elapsed / total time, right in your status bar.

Pause and the track stays visible. Stop playback or shut down the server and it disappears. Choose the width, add the artist, and place it wherever you like.

Set up the tmux plugin

Put #{vtamp} in your status format before loading the plugin. No clock or date required.

set -g status-right \
  '"#{=21:pane_title}" #{vtamp}'

BUILD FROM SOURCE

Clone the repository, then install:

# Get the source
git clone https://github.com/rath/vtamp.git
cd vtamp

# Install the player
cargo install --locked --path .

# Register your music folder
vtamp library add ~/Music

# Attach. Pick a track. Press Enter.
vtamp

No permanent pane required. q to detach.
