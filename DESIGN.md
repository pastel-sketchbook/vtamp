# vtamp visual system

User-approved direction: classic Winamp, rendered as a useful terminal instrument.

Charcoal panels (#202321), near-black displays (#101510), phosphor green (#b4f676), warm off-white (#eeeae0), muted sage (#a4b19b), amber errors (#efbc72). Compact square corners and fine panel borders. Green communicates active playback and focus, not every decoration.

The TUI is an Operate surface: queue, library, current track, timing, and key hints have priority. Cover art gives context without dominating the queue. At narrow widths use tabs, and at tiny sizes preserve text controls.

The website is a Persuade surface. Lead with “Music stays. Your terminal moves on.” and a working, explicitly simulated detach demonstration. Follow with the detachable lifecycle, executable CLI examples, and source installation instructions. A broad typographic headline is balanced by a dense, mechanically precise player. No invented metrics or release claims.

Use self-hosted Space Grotesk for web headings/body and the system monospace for commands and player data. Keyboard focus is explicit; reduced motion removes transitions. All public music names and covers are authored demo content.
